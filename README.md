# calc コマンド
## 標準入力から読み込んだ数式を計算する。
### 入力
$ echo “数式” | ./calc で利用できる。

- 注意事項
  - 数式に含まれる空白、計算に利用できない文字は読み飛ばして計算を行う。
    ```ruby:実行例
    $ echo “2abc+3” | ./calc
     5.0

    $ echo “2 + 3” | ./calc
     5.0
    ```


- 四則演算
  - 正には “+” 負には “-” 積には “*” 除には “/” を使用することで計算できる。
``` ruby:実行例
$ echo “5+3” | ./calc
 8.0

$ echo “8-3” | ./calc
 5.0

$ echo “2*3” | ./calc
 6.0

$ echo “4/2” | ./calc
 2.0
```

- 括弧の優先処理
  - 括弧は ”( )” のみ利用できる。
  - 暗黙の積算は利用できる。
  
``` ruby:実行例
$ echo “2*(2+3)”| ./calc
 10.0

$ echo “10/(2*(2+3)) | ./calc
 1.0

$ echo “2*(2+3)-3*(1+2) | ./calc
 1.0

$ echo “2(2+3)-3(1+2)” | ./calc
 1.0
```

- 三角関数
  - sin,cos,tanのみ利用できる。
  - sin(度数)、度数の計算が必要ない場合はsin度数で利用できる。
``` ruby:実行例
$ echo “sin(90)” | ./calc
 1.0

$ echo “cos(10+35)” | ./calc
 0.7071067811865476

$echo “tan(100-10) | ./calc
 1.633123935319537e+16

$ echo “cos45” | ./calc
 0.7071067811865476
```
